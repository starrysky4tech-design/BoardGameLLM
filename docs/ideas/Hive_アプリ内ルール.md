# Hive アプリ内ルール(要約)

- 出典: Android版 Hive(`com.jb.hive.android` 19.3.1)の Rules > Main tutorial(全12ページ)と Rules > Edge cases。2026-10-31 に実機で読んだ内容
- 本書はアプリ内の説明を正本とする。外部のルール解説と違う場合はアプリ内を優先する
- 未読: Rules の Ladybug / Mosquito / Pillbug(拡張駒の説明)、Edge cases の詳細、Download Rules
- 出典ページは `(Tutorial n/12)` で示す

## 目的

相手の女王を、6方向すべて(隣の6マス)を埋めて完全に囲む。先に囲んだほうの勝ち。
(Tutorial 1/12)

## 開始

- 盤は空の状態で始まる。白が先に駒を置き、黒がその隣に置く(Tutorial 2/12)
- 1手目の女王の制限: `Tournament Rules` を有効にすると、双方とも1手目に女王を置けない(Tutorial 12/12)。実機では無効(チェック無し)で対局した
- 手持ちは種類ごとに重ねて表示される。実機の表示から目視で数えた数(要確認): アリ3、カブトムシ2、バッタ3、クモ2、女王1(拡張駒は含まない)

## 1手番の行動

- 手番ごとに「駒を置く」か「駒を動かす」のどちらか1つを行う(Tutorial 3/12)
- 駒を置くとき、相手の駒の隣には置けない(Tutorial 3/12)。自分の駒の隣に置く
- 置き先は、青い六角形で示される(実機で確認)

## 女王の期限

- 各プレイヤーは、自分の4手番目までに女王を置く(Tutorial 4/12)
- 女王を置くまで、その人は駒を動かせない(Tutorial 4/12)

## ワンハイブ規則

- 駒を動かして、駒の集まり(ハイブ)を2つに割ることはできない(Tutorial 5/12)
- 割れる手は禁止。実機では、動かせない駒を選ぶと「Ant cannot move because this would break the hive in 2.」と表示された

## 駒の動き

| 駒 | 動き | 出典 |
|---|---|---|
| 女王 | 1手で1マス | Tutorial 6/12 |
| カブトムシ | 1手で1マス。ほかの駒の上にも乗れる。上に乗る駒があると、その下の駒は動けない | Tutorial 7/12 |
| バッタ | 直線上に並んだ駒の列を、1つ以上越えて、越えた先の最初の空きマスへ跳ぶ | Tutorial 8/12 |
| クモ | ちょうど3マス、同じ道を戻らずに動く | Tutorial 9/12 |
| アリ | ハイブの周りを、どこへでも動ける(ただし下の滑り込みの制限に従う) | Tutorial 10/12 |

## 滑り込みの制限

- カブトムシとバッタ以外は、目的地へ「滑り込める」場合だけ動ける(Tutorial 11/12)
- 例: 2つの駒が門の形(ゲート)を作ると、その間を通れない(Edge cases 1/2・2/2)
- 目的地へ物理的に滑れない移動は禁止

## 勝敗

- 相手の女王が6方向すべて埋まると、その時点で囲んだ側の勝ち
- 実機の表示: 勝った後は上部のバーが `White won!`(白が勝った場合)に変わり、盤は操作できない
- 両者の女王が同時に囲まれた場合の扱い: 未確認
- パス(動ける手が無い場合): 未確認

## 拡張駒(Expansions)

実機では Expansions を全て未選択にして対局した。以下は Rules の説明(出典: `Rules > Ladybug / Mosquito / Pillbug`)。

### Ladybug(てんとう虫、Tutorial 1/2・2/2)
- 3マス動く。最初の2マスは他の駒の上に乗り、最後の1マスで下りる
- 2マス目までの移動は、必ず駒の上に乗った状態で行う
- 上に乗るため、カブトムシのように相手の駒の出入りを阻む(囲まれたマスへ出入りできる)
- カブトムシより速い

### Mosquito(モスキート、Tutorial 1/3〜3/3)
- 動く前に隣接している駒の、どの色の駒でも、その駒の動きを使える(動きは手ごとに変わる)
- 例外: 隣接する駒がモスキートだけの場合は、動けない
- ハイブの上に、カブトムシとして動いて乗った場合、そのまま下りるまでカブトムシとして動く

### Pillbug(ダンゴムシ、Tutorial 1/5〜5/5)
- 1マスずつ動く。さらに特殊能力を持つ
- 特殊能力: 隣接する、重なっていない駒(味方でも相手でも)を、2マス動かす。上にダンゴムシへ乗せ、その後に自分の隣の空きマスへ下ろす
- ハイブを2つに割る移動は、ダンゴムシの移動も含めて禁止
- 重なった駒の山からは動かせない(ダンゴムシ自身が山の中にある場合も含む)
- 直前に相手が動かした駒は、ダンゴムシで動かせない
