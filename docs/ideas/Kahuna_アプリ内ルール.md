# Kahuna アプリ内ルールの要約と実機で確認した事実

出典: Kahuna 1.7(`com.usm.kahuna`)のタイトル画面「RULES」(全9ページ、英語)と、SHG11 での実機確認(2026-10-30)。
英文の転載ではなく、日本語で要約した。ルールのテストの出典には、ページ名(`PLAYING CARDS` など)を書く。

> **ルールページ(starrysky.sakura.ne.jp)との食い違い**は末尾にまとめた。実装は**アプリ内ルール**に従う。ただし**途中終了は、ご指示により適用しない**(設定で切り替え可)。

## アプリ内ルールのページ別要約

| ページ | 内容 |
|---|---|
| THE STORY | 2人の司祭が12の島に橋を架けて争う。ある島に橋を十分に架けると、その島を支配する |
| GETTING STARTED | 24枚のカードを混ぜ、各プレイヤーに3枚配る。カードは12の島のどれかの名前を持つ。3枚を表向きに並べ(場札)、残りを裏向きの山札にする。1手番に**0〜5枚**のカードを使える。使い終えたら1枚引く。**手札は5枚を超えない** |
| PLAYING CARDS | カード1枚で、そのカードの島と隣の島を結ぶ**空いている点線に橋を1本**置く。複数枚使うときは1枚ずつ。カードを使う**代わりに**、1枚以上を**伏せて捨て札の下に捨てる**こともできる。1枚も使わなくてもよい |
| KAHUNA STONE PLACEMENT | ある島に接する点線の**半分より多く**に自分の橋があれば、その島を支配し、カフナの石を1つ置く。支配を得たとき、その島に接する**相手の橋はすべて取り除かれる**。それで隣の島の支配を失った相手は、その島の石も取り除かれる |
| REMOVAL OF AN OPPONENT'S BRIDGE | **2枚1組**のカードで、相手の橋を1本取り除ける。2枚は、その橋が結ぶ**2つの島の名前だけ**でなければならない。橋が FAAA–ELAI なら「ELAI+FAAA」「FAAA+FAAA」「ELAI+ELAI」のどれか |
| DRAWING AN ISLAND CARD | 使い終えたら、**場札3枚のどれか、または山札の一番上**から1枚引く。**引かない**ことも選べるが、その場合は**次の手番で相手が必ず引く**。手札が5枚なら、**先に1枚以上を捨てる**。引く(または引かないと宣言する)と手番が終わる |
| IN-BETWEEN SCORE | 1・2ラウンド目は、山札と場札の最後の1枚が取られたら決算。支配している島(カフナの石がある島)の数を数え、同数なら得点なし。1ラウンド目は、多い方が**1点** |
| FINAL SCORE AND END OF THE GAME | 2ラウンド目の後は、多い方が**2点**。3ラウンド目は、カードがすべて取られた後に**各プレイヤーがもう1手番**行って終了し、島の数の**差が得点**になる。3ラウンドの合計が多い方の勝ち |
| A TIE OR ENDING IN BETWEEN | 同点なら、**3ラウンド目の得点が多い方**の勝ち。それでも同点なら**盤上の橋が多い方**の勝ち。それでも決まらなければ引き分け。**2・3ラウンド目に、盤上の橋が0本になったプレイヤーがいたら、その時点で相手の勝ち** |

## 盤面(実機で確認)

- 島は12(`ALOA` `BARI` `COCO` `DUDA` `ELAI` `FAAA` `GOLA` `HUNA` `IFFI` `JOJO` `KAHU` `LALE`)、点線(橋を置く場所)は**27本**。
- 各島の点線の数は、ALOA 3、BARI 5、COCO 4、DUDA 4、ELAI 6、FAAA 5、GOLA 4、HUNA 5、IFFI 5、JOJO 5、KAHU 5、LALE 3(合計54 = 27×2)。
- 手札のカードを選ぶと、その島に接する**空いている点線**に照準マークが出る。実機で ALOA(3本)、COCO(4本)、ELAI(6本)、HUNA(4本、残り1本は相手の橋で埋まっていた)を確かめ、地図からの読み取りと一致した。
- 点線の位置は [board.json](../../src/bglm/plugins/kahuna/data/board.json) にある(画像座標、2432×1080)。照準マークから確認できた18本は `verified`、地図から概算した9本は `estimated`(Phase 5 で較正する)。
- カードの名前の下にある縦線は、その島の点線の数と一致するように見える(ALOA と LALE は3本)。Phase 5 の認識の検証に使える。

## 操作(実機で確認)

| 操作 | 手順 |
|---|---|
| 橋を置く | 右の束の手札のカードをタップ → 照準マークをタップ |
| 選択の解除 | 選んだカードをもう一度タップ |
| 引く | 下端の場札のカードをタップ(手札が5枚だと引けない)。山札の引き方は未確認 |
| 捨てる | カードを選ぶと左下に「DISCARD」の表示が出る。そこへ捨てる操作は未確認 |
| メニュー | 左下。「MENU」でタイトルへ戻る(進行は保存される)。「GIVE UP」は降参なので使わない。「SHOW TIPS」でチュートリアルの案内を切り替えられる |
| 再開 | タイトルで「PLAY」を押すと、保存された対戦があれば「NEW GAME / RESUME」の確認が出る |

## ステージ

- ステージ選択は、12の島に1つずつ並んだ進行マップ。**有効なのは最初のノードだけ**で、他は暗い(順に解放される形に見える)。
- 最初のステージには、英語の案内(チュートリアル)が出る。「SHOW TIPS」の設定で切り替えられるとみられる。
- したがって、評価に使えるステージは**ステージ1**のみ。他のステージの難度は、解放するまで確認できない。

## 未確認

- (解決済み)カフナコマの個数。10個とご確認いただいたが、実機で1人が11島を支配した。島は12なので、12個かもしれない。いずれにせよ上限は効かないので、実装では扱わない。
- 決算の後、山札と場札をどう作り直すか(ルールページには「捨て札を混ぜて新しい山札にする」とある。手札は残ると見られる)。
- 山札から引く操作と、捨てる操作の手順。
- 相手の手番の表示、決算画面、終了画面(Phase 7 のログで撮影する)。

## ルールページ(starrysky)との食い違い

| 項目 | ルールページ・ご回答 | アプリ内ルール | 実装での扱い |
|---|---|---|---|
| 途中終了 | なし(杖コマ0本でも敗北にならない。ご指示で、何度も確認いただいた) | 2・3ラウンド目に盤上の橋が0本になると、相手の勝ち | 既定は**なし**(ご指示に従う)。設定で切り替えられる |
| 同点の判定 | 橋(杖コマ)の数で判定。同数なら同点 | 3ラウンド目の得点 → 橋の数 → 引き分け | アプリ内ルールの順 |
| 3ラウンド目の終わり | 3回目の決算で終了 | 最後のカードが取られた後、各プレイヤーがもう1手番行ってから終了 | アプリ内ルールに従う |
| カードを使う代わりの「捨てる」 | 記載なし | あり | 手に含める |
| 引かない選択 | 記載なし | あり(相手が次に必ず引く) | 手に含める |

## 対戦画面の見た目(ユーザーが遊んだ1ゲームの記録から。173枚、`datasets/phase5/session1/`、Git管理外)

画面は2432×1080。左端に約60pxの黒帯がある。

| 項目 | 見た目 |
|---|---|
| 自分と相手 | **右上の「STARRYSKY1970」が自分**、**左上の「FISHERMAN」が相手**(相手の動きは「FISHERMAN PLAYS FAAA - JOJO」のように、盤の上部に黄色い小さな文字で出る) |
| 自分の手番 | 右の束(自分の手札)が**明るい** |
| 相手の手番 | 右の束(自分の手札)が**暗く沈む** |
| 手札 | 右の束。後ろのカードは名前の**頭文字しか見えない**が、12島の頭文字はすべて違う(A〜L)ので、頭文字で島が決まる |
| 場札 | 下端の3枚。1枚取られると、その枠が空く |
| 山札 | 下中央の赤い丸の数字(残り枚数) |
| 杖コマ | 自分は**白い棒**、相手は**黒い棒**(点線の位置に置かれる) |
| カフナコマ(支配の印) | 島の上の**丸い印**。自分は明るい(白縁)、相手は暗い(黒縁) |
| ラウンドの切り替え | 「READY FOR A NEW ROUND」の帯。その前に、決算のダイアログ「END OF ROUND n」(島の数、得点、ROUND WINNER、CONTINUE)が出る |
| ゲーム終了 | 3ラウンド目の「END OF ROUND 3」のダイアログ(勝者の名前つき) → CONTINUE → ステージ選択へ戻る。別の「終了画面」は無い |
| ステージ | 勝つと次のステージが解放され、ランクが上がる(1ゲーム目の前後で Rank 15 → 65、アイコンも変わった) |
| 手札の持ち越し | ラウンドが替わっても、手札は残る(ラウンド2の最初に手札が5枚だった) |
| カフナコマの個数 | 最終ラウンドで**1人が11島を支配**した(結果「CONQUERED ISLANDS 0 | 11」)。10個の上限は無い。島は12なので、12個なら上限は効かない |
