# 設計書

## アーキテクチャ概要

`plugins/monopoly/vision/cash.py` を追加する。既存の `toolkit/template_reader.py`(`TemplateReader`)を数字の分類に使う。新しい読み取り手段は作らない。

```
plugins/monopoly/
├── vision/
│   ├── screens.py       (既存)
│   └── cash.py          (新規) 所持金の切り出し・桁の分割・読み取り
└── data/
    └── digits/          (新規) 0〜9 のテンプレート(小さい画像のみ。Git 管理)
datasets/eval/monopoly/cash/   (新規、Git 管理外) 画像 + labels.json
scripts/monopoly/              (新規) 評価・テンプレート切り出しの補助スクリプト
```

## コンポーネント設計

### 1. 切り出し(`cash.py`)
- 所持金の表示領域を、固定の矩形で切り出す(自分: 左、AI: 右)。矩形の座標は、手順 3 の観察で決める。実機の画像 1 枚の推測では決めない
- 背景は盤が透ける。前景(数字)の色を閾値で抜く。色の条件は、観察した複数フレームの前景と背景の分布から決める

### 2. 桁の分割
- 前景画素の連結成分を、左から並べる
- Phase 0 の不安定は「桁がつながる」「細い数字が割れる」。次の 2 つで扱う:
  - つながった成分は、数字の想定幅(テンプレートの幅)で分割する。分割後の各片が閾値以上で一致しなければ「不明」
  - 割れた成分(細い「1」など)は、近接する成分を結合して試し、一致度の高い解釈を採る
- 桁数(1〜6)と全体の幅が想定外なら「不明」

### 3. 分類
- 各桁を `TemplateReader` に渡す。信頼度は桁の最小値
- 通貨記号(₼)は、数字の前の固定位置のため、領域の切り出しから除く(位置が動くなら、記号のテンプレートを別に持って位置合わせに使う)

### 4. 安定した読み取り
- `read_cash_stable(io, interval)`: 間隔を置いた 2 枚を読み、一致したときだけ値を返す。一致しなければ、もう 1 枚読んで 3 枚中 2 枚の一致を採る。それでも一致しなければ不明
- 更新の遅れ(表示の追従)は、待ちでは解決しない場合がある(第 21 手番)。一致=正しい、ではなく「画面の表示と同じ値」を返すだけで、整合検査は計画 3 で行う

## データモデル

```python
@dataclass(frozen=True)
class CashReading:
    value: int | None      # 不明なら None
    confidence: float      # 桁の最小値。不明なら 0.0

@dataclass(frozen=True)
class CashPair:
    me: CashReading
    ai: CashReading
```

## 読み取りの失敗の扱い
- 例外にしない。不明(`value=None`)を返す(Kahuna の `numbers.py` と同じ方針)
- 閾値は `config/monopoly.toml` ではなく、ここでは定数 `MATCH_MIN` に置き、評価で根拠を書く(`docs/05`「パラメータ境界値の設計」に従い、根拠をコメントに残す)

## テスト戦略

- ユニット: 合成画像(実機の数字テンプレートを並べた画像)で、桁の分割(つながる・割れる)と不明の経路を確かめる。期待値は手で書く
- 評価: 実機の画像の評価セットで、誤読 0 を確認する(`scripts/monopoly/eval_cash.py`)
- 汎化: テンプレートは評価セット A から切り出し、評価は別の局の B で行う

## 実装の順序

1. 実機から画像を集める(読み取り専用)
2. 数字の見た目を観察して、切り出し矩形・前景の色・桁の幅を決める
3. Phase 0 の不安定の原因を、集めた画像で再現して切り分ける
4. 実装する
5. 評価して、受け入れ条件を満たすか判断する

## 受け入れ条件を満たさなかった場合
- 誤読を 0 にできない場合は、原因(桁の分割、字形の変動、背景の透け)を `RESULT.md` に書き、読み取り手段の変更(CNN の分類など)を別計画にする。誤読を許容して先へ進まない

## セキュリティ考慮事項
- 画面取得のみで、入力は送らない。`adb` は `-s 355092380222016` を付ける
- 集めた画像は `datasets/` に置く(Git 管理外)

## パフォーマンス考慮事項
- 切り出しは 2 領域のみ。全画面の走査はしない
- テンプレートは起動時に 1 回読み込む
