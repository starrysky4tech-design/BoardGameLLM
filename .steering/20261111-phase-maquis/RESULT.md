## 操作の流れ(確認済み)

- **配置**: 地点をタップ(白い枠で強調)→ 右列の1枠目(自転車)をタップ。**2タップ**。確認ダイアログは出ない
  - 配置のたびに巡回が自動で出現し、ログに「ミリス隊員が○○に出現」と出る。アニメーションは約2.5秒で、その間は次の入力を待つ(2.5秒待てば取りこぼさなかった。下限は未測定)
  - 左の `N/M` は、未配置の団員の数/団員の総数。N が 0 になるまで、**フェイズ終了ボタンは出ない**(右列の最下枠が空のまま)
  - 巡回が来た地点には赤い「!」(帰還不可)が出る。巡回が居る地点にも配置はできる(赤い「!」の円がその地点に出る。その団員は帰還できず捕縛される)
  - 任務の枠にも配置できる(任務の絵に団員の顔が重なる)。配置先の地点は自分の団員の顔で表示され、ターンごとに顔が変わる
- **行動**: フェイズ・ターン終了で行動フェイズへ(アイコンが旗)。緑の枠の地点をタップ(白い枠)→ 右列にその地点の行動が並ぶ → 押す。効果は資材の増減に即時で出て、団員は経路があれば帰還する(ログ「マキ団員が○○で行動し帰還した」)
  - 経路が無ければ「…で行動したが帰還できない」と出て、ターン終了時に「…で捕縛された」となり、団員は監獄に移る
  - 任務の枠をタップしても、行動の枠(★の丸)が右列に出る
- **ターン終了**: 行動フェイズで同じ位置のボタンを押す。次のターンの配置フェイズが始まる(約4秒)
- 配置フェイズの終了ボタンと行動フェイズの終了ボタンは同じ位置・同じアイコン(時計とチェック)

## 帰還できない配置の見分け方(3ゲーム目で確認)

- 団員を1人置くたびに巡回が1つ増え、**巡回が来ると、隠れ家へ戻れなくなる地点に赤い「!」が付く**。「!」は配置のたびに更新される(例: 食料品店に巡回 → 右下の空き部屋に「!」)
- 3人目まで置き終えた時点で、自分の団員のいる地点に「!」が無ければ全員帰還できる。1人ずつ置いて確かめれば、捕縛を避けられる
- 隠れ家に隣接する畑(左右)とカフェは、巡回が3つ来ても「!」が付かなかった(1回の観測)
- 設計への含意: 配置の合法手は「置ける地点」全部だが、**良い手は「置いた後に自分の全団員の帰還経路が残る」配置**に限られる。`apply` は巡回の位置を知らないので、確率(山札の残り)で捕縛の危険を見積もる。画面の「!」と地点の橙の数字(巡回が来る札の枚数)は、見積もりの照合に使える

## 巡回の規則(3ゲーム目で確認。ログ・捨札・橙の数字がすべて一致)

- **巡回は、引いたカードの①②③のうち、団員も巡回もいない最初の地点に出る**。団員のいる地点は①でも飛ばされる
- 山札(10枚)は引くたびに減り、**捨札は新しい順に左から並ぶ**。1ターンに3枚引く(団員3人 × 1枚)。ターン開始時の橙の数字の合計は、山札の残り枚数(10 → 7 → 4 → 1)
- 橙の数字 = 「いま団員を置く地点を選んだ場合に、次に引くカードで巡回が出る地点ごとの残り枚数」。地点を選ぶと、その地点を飛ばした分に再計算される(実機の数字がそのまま確率の根拠になる)
- 巡回はターンの終わりに消える(次のターンの開始時に巡回の絵が無い)。山札はターンをまたいで減り続ける(ターン4の開始時に残り1枚)
- **山札が空のとき、次の1枚を引く前に、捨札の全10枚(そのターンに先に引いた分も含む)を混ぜ直す**(ターン4で確認: 1人目の配置で最後の1枚を引き、2人目の配置の直前に山札が10枚に戻って1枚引かれ、山札9・捨札1になった)。混ぜ直し後の数字(故買屋2・バラダ2・ポン・レヴェック3・食料品店2)も、全10枚から計算した分布と一致した
- 3地点とも団員か巡回で埋まったカードは、地図上に**暗い赤の数字**(ポン・レヴェックに「1」)で表示される。捕縛の印と見られるが、実際に引かれた場面は未観測(捕縛される地点・人数は未確認)
- **巡回のいる地点には団員を置けない**(その地点を選んでも、右列に配置ボタンが出ない)。巡回が置かれる前に置く必要がある

## 任務と捕縛(4局目 とても簡単・スパイ支援/工場破壊で確認、2026-11-11)

- **任務の箱の読み方**: 詳細欄の1つの箱 = 「費用 → ★」で、右下の小さな数字は**必要な団員の人数**。スパイ支援は `銃器2 → ★ [1人]`、`(資金・食料などの費用) → ★ [2人]`。工場破壊は `★ [1人]`、`★ [1人]`、`爆薬 → ★ [2人]`(最初の2つは費用なし)。左上の★の数(A=2、B=3)が箱の数
- **任務の枠は地点と同じように団員を受ける**(任務の枠を選んで、右列の配置ボタン)。行動フェイズに枠を選ぶと、実行できる箱が右列に「★」で並ぶ。実行すると★が点灯し、**ターンをまたいで残る**(2ターンかけて2つ点灯)
- **任務の枠の場所**: 任務A=故買屋の地点、任務B=ポン・デュ・ノールの地点。枠の「!」は、その地点に巡回がいる、またはその地点が帰還不可のときに付く(観測8件で矛盾なし)
- **任務の枠の団員は、その地点への巡回の出現を塞がない**。4局目ターン2で、任務Bの団員がいるのにポン・デュ・ノールに巡回が出現し、団員は「行動したが帰還できない」→ 捕縛された(★は点灯した)
- **捕縛された団員は監獄に入り、次のターン以降も戻らない**: 4人のうち1人が捕縛されると次のターンから `3/3`、監獄に団員の顔。ターン4でも戻っていない。監獄の枠は選べない(戻す手段は画面に無い)。「とても簡単」は、捕縛で士気は下がらなかった(士気の丸は6のまま)
- 全団員が捕縛されると、そのターンの終了時に壊滅(2局目、4局目の1ターン目)。※4局目の1ターン目は私の確認ミス(「!」が並ぶ配置で終了を押した)。戦績の壊滅は通算3

## 画面の読み方(認識の実装で確かめたこと、2026-11-11)

- **地点の在・不在**: 画面は決まった絵なので、空き地の基準画像との相関が 1.00 で一致し、写真(団員・巡回)が出ると 0.6 未満になる。巡回か団員かは、紺色の画素の割合(巡回 0.24〜0.37、団員 0.00)
- **カフェだけは基準画像が使えない**: カフェには、勧誘できる人の小さな写真が常に出る(対局ごとに顔が違い、勧誘で 2人 → 1人 と減る)。団員の写真の枠(上端 y=888)があるかで判定する(飾りの写真の枠は上端 902)
- **赤い「!」の出方**: 巡回に塞がれた地点を通らずに隠れ家から行ける地点の、さらに隣まで「戻れる」。それ以外(巡回のいる地点自体を含む)に「!」が付く。観測4件の全リストと一致(`Board.marked`)。任務の枠の「!」は、その地点が巡回のいる地点か「!」の地点のとき
- **資材の丸**: 塗り(明るい)・空(暗い)で数える。士気は 4つ + 3つの2行。「N/M」は文字なので、濃い塊3つに分けて、24×36 に伸ばしたテンプレートと照合する(0〜4 を実機で確認。5 は未見)
- **★は下から点灯する**(任務B: 3つ目の位置から)。任務の種類は、絵の上端の帯で判別する(スパイ支援・工場破壊は確認済み。暗殺は未対応で止まる)
- **カードの絵**: 山札の画面のカード枠は 446px 間隔で、①②③の絵は枠の左から +95〜+215px。地点ごとに固有の絵(10種)。同じ地点でも見え方が2通りに割れる(スクロール位置の違い)ので、テンプレートを複数持つ
- **士気**: ターントラックのオレンジのターン(3)の開始時に、6 → 5 になった(3局目、4局目で観測)。**認識の照合では士気を比べず、画面の値を採る**(ルールに入れるまで)
- **全画面の判別**: 山札の画面もパネルがクリーム色なので、終局のダイアログより先に見出しの絵で判別する。「完全版を入手」のある終局画面・タイトルは、どちらも「想定外の画面」として入力を送らない
