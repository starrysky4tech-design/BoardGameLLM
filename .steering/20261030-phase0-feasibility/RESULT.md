## 設計への含意

- **使えるVRAMは約2.9GB**: デスクトップだけで1.17GBが使われているので、`docs/01` の「4GB以内」は実質2.9GBが上限。
- **VLMの数え上げは信用できない**: 重なったカードの枚数や名前を全体画像から読ませるのは不適切。`docs/01` のとおり、テンプレートマッチングを第一にし、VLMは切り出した1要素の分類だけに使う。
- **VLMの暖機が必要**: 初回の読み込みに166秒かかる。実行ループの開始前に空の呼び出しで暖機する。
- **Kahunaの1手の時間**: 画面取得で約1秒。認識と思考を足しても、`docs/01` の「1手30秒以内」に十分収まる見込み。


## 大戦略SSB2（PC）

検証マップは「ハロー・大戦略」（難易度★1、2勢力、BLU vs RED、生産あり・首都占領あり）。ウィンドウは 1280×720（クライアント領域）、枠あり。

| 項目 | 結果 |
|---|---|
| ウィンドウの特定 | 題名が「大戦略SSB2」と**完全一致**するウィンドウで特定できた（VS Code など、題名に含むだけのウィンドウを除外するため完全一致が必要） |
| 画面取得（PrintWindow） | **成功**。他のウィンドウに隠れていても内容を取得でき、20〜40ms |
| 画面取得（mss） | 前面にあれば成功（約110ms）。**ゲームが隠れているとその上のウィンドウが写る**。隠れた状態の取得には使えない |
| クリック | **「移動 → 150ms待機 → 押す → 100ms待機 → 離す」にしないと届かない**。`pydirectinput.click()` の即時クリックは、ハイライトは動くが押下が無視された |
| 座標の一致 | クライアント座標で指定した位置に届く（マップ行の選択、開始ボタン、首都の建物、×ボタンで確認） |
| キー入力 | `d`/`a` でカメラが動き、戻すと元の視点と差分約2（届く）。管理者権限は不要だった |
| ホイール | `win32api.mouse_event` でリストのスクロールができた（1ノッチ=120） |
| 前面化 | `SetForegroundWindow` は時々失敗する（エラー6）。**Alt キーの押し離しを挟んで再試行**すると安定した。入力は前面でなければ送らない |
| 起動時の位置 | ゲームのウィンドウは左側のサブモニターにあり、スクリーン座標が負になる（`-1909,50`）。mss・クリックともに問題なし |
| 表示 | 斜め上からの3D透視。ヘクスは手前ほど大きく、形が歪む。ヘクスの枠線は緑で、「OFF」ボタンで切り替えられる |
| カメラ | `d`/`a` で左右移動、`v`/`r` で縮小/拡大。3回押して戻すと元の視点との差分約2.9で、完全には戻らない |
| 全体の見え方 | 縮小すると小さな島のほぼ全体が1画面に入る。首都を選ぶと左に情報パネル（首都、地形防御60）が出る |
| 画面上部の数値 | ターン数 1/99、部隊数 0/50、軍資金 25,000、保有燃料 0、工業力 5。文字は1280×720で読める |

### 生産画面（兵器の性能データの取得元）

首都の建物をクリックして開く。1280×720で次の項目がすべて読める大きさで表示される。

- 兵器の一覧（兵器タイプ、名称、価格）
- 編成数、燃料、士気、移動高度、移動力、索敵範囲、対高空・対低空・対地海・対海中防御、対ミサイル防御、地形防御補正
- 武装ごとの名称、射程、対航空・対ヘリ・対車両・対歩兵・対艦船・対潜水の攻撃力、弾数
- 14種の地形ごとの移動力消費（進入不可は「—」）

→ `WeaponSpec` と `move_cost` は、この画面を兵器ごとに撮影して読み取れば作れる。ルールブックに無い項目をここで補える。

### 設計への含意（大戦略SSB2）

- **取得はPrintWindowを既定にする**: 前面でなくても取れ、速い。mssは前面のときだけ使う。
- **入力は前面化とタイミングが要る**: 前面化の再試行、クリックの待機は共通基盤の `InputDriver` に入れる。
- **キャリブレーションは射影変換**: ヘクスの枠線（緑）が見えるので、ヘクスの格子を検出して推定できる見込み。カメラ操作で視点がずれるため、ターンごとに再推定するか、ヘクスの座標を画面の目印から求める。
- **小さなマップは1〜数枚で足りる**: ハロー・大戦略は縮小すると島全体がほぼ収まる。64×64の大マップはスクロールが必要。
- **シナリオマップは別ルール**: マップリストの先頭から約20個は「シナリオマップ」で、**部隊の生産ができず、敵部隊の全滅でクリア**。`docs/01` のルール（首都占領・生産あり）の対象は、それ以外の通常マップ。
