# Phase 0 結果(実機で確かめた事実)

確認日: 2026-10-31 / 端末: SHG11(`355092380222016`、Android、1080x2432、回転 0)
素材: `datasets/raw/hive/feasibility/`(Git管理外)

## アプリ

- パッケージ `com.jb.hive.android`、versionName 19.3.1(versionCode 544)、targetSdk 35、起動 `.StartActivity`
- 起動は `monkey -p com.jb.hive.android -c android.intent.category.LAUNCHER 1`。離れるときはHOMEキー

## 座標系

- `screencap` の画像(1080x2432)の座標をそのまま `input tap` に渡して正しく反応した(Kahunaと同じ)

## 画面と操作

| 項目 | 事実 |
|---|---|
| 起動画面 | `LOCAL PLAY`(CPU戦と2人対戦)と `ONLINE PLAY`。**ONLINE は使わない** |
| LOCAL PLAY を押すと | すぐ対局が始まり、チュートリアルのダイアログ(VIDEO / キャンセル / TUTORIAL)が出る。「キャンセル」で閉じる |
| 色 | 自分は黒(`You are Black` のトースト)。**相手(白)が先に女王を置いた状態**で始まった。`Computer Color` で変更できる |
| 駒の構成 | 基本の8種(アリ3、カブトムシ2、バッタ3、クモ2、女王1)。拡張(てんとう虫、モスキート、ダンゴムシ)は `Expansions` で全て未選択 |
| 手番表示 | 上部のバーの文字。自分の手番が続く間は `Black's turn` のまま(相手の手番の表示を見られなかった。相手の応答が約0.6秒以内だったため) |
| 手持ち | 画面下が自分(黒)、上が相手(白)。種類ごとに重ねて表示。選ぶと赤枠 |
| 置く手 | 手持ちをタップ → 置き先の候補が青い六角形で出る → 候補をタップで置く。**2タップ** |
| 相手の直前の手 | 動かした駒の移動先と、移動元の空きマスが**緑枠**で出る |
| 盤の位置 | 駒を置いたりメニューを操作すると、盤が上下にずれることがある(同じ盤面で約63px)。座標は固定ではない |
| 禁止された選択 | 動かせない駒を押すと、画面下にトースト(`Ant cannot move because this would break the hive in 2.`)。入力の失敗の検知に使える |
| メニュー(右上⋮) | Main Menu、Level、Hint level、Computer Color、Display、Rules、Statistics、Save and load、Expansions |
| Level | 2 player(Pass and play)、Beginner、Easy、Medium(既定)、Difficult、Expert、Master (slow) |
| Rules | Tournament Rules(チェック無し)、Video、Main tutorial、Ladybug、Mosquito、Pillbug、Edge cases、Download Rules |
| Edge cases | カブトムシ/ダンゴムシが2段目で作る「ゲート」により、滑り込めない移動が禁止される(2枚の図) |

## 判断

- **Go**: 画面取得・タップ・認識に使える手がかり(青枠の合法手、緑枠の直前の手、トースト)が揃っている。CPU戦は戦績が変わってよいと確認済み(ONLINE は対象外)
- 最初の評価対象のレベルは Medium(既定)。Level は設定で変えられるので、強さの検証は上げ下げして行う

## 対局の記録(2026-10-31、Medium、Expansions なし)

- 白の勝ちで終局。こちらは黒。手数は未計数(概算で約20手)
- 終局画面: 上部のバーが `Black's turn` から `White won!` に変わる。盤の操作はそれ以上受け付けない。終局の判定に使える
- 盤上の駒を動かす操作は確認済み: 盤上の駒をタップ → 移動候補が青枠、移動元が赤枠 → 候補をタップ(バッタ、アリで成功)
- 動かせない駒を選ぶと `... break the hive` のトーストが出る(再掲)
- 相手(白)の手の表示は、移動先が緑枠、移動元が空きマスの緑枠(アプリの画面で確認)
- 勝因の詳細は未検証。終局画面は黒の女王の周りが埋まった局面(画面上の判定は未確認)
- 未確認のまま: パス(動かせる手が無い場合の表示)、盤の拡大・移動(ピンチ)、カブトムシが積み重なった時の見え方(今回は積み重ねを作らなかった)

## Phase 0 の判断(確定)

- **Go**(2026-10-31)。画面取得・タップ・合法手の表示(青枠)・移動元と移動先の表示(緑枠)・終局の表示(`White won!`)・トースト(禁止手)が揃っており、認識と操作の両方に使える
- 拡張駒(Ladybug、Mosquito、Pillbug)は、実機では未選択。最初の実装は基本の8種(アリ、カブトムシ、バッタ、クモ、女王)に限り、拡張は後の段階に回す。説明は `docs/ideas/Hive_アプリ内ルール.md` に書き起こし済み
- 未確認の2点は、設計の既定値を置いて実装後に確かめる:
  - パス: 動ける手が無いときだけ許す。アプリにパスの表示があるかは、局面が来たときに画面で確かめる
  - 両女王が同時に囲まれた場合: 既定は「引き分け扱いで停止」。アプリの表示を確かめるまで、勝敗を決めつけない
